# Portfolio Website

A personal portfolio website built with HTML, CSS, and Tailwind CSS. It showcases an About section, skills, services, selected projects, and contact details in a modern single-page layout.

## Features

- Responsive portfolio landing page
- Tailwind-based styling
- Project showcase cards
- Skills and services sections
- Contact and resume call-to-action
- Dark mode toggle support
- Mobile-friendly navigation

## Project Structure

```bash
portfolio/
├── index.html
├── package.json
├── package-lock.json
├── pics/
│   └── ...
├── src/
│   ├── input.css
│   └── output.css
└── README.md
```

## Tech Stack

- HTML5
- Tailwind CSS
- JavaScript
- Font Awesome icons
- Google Fonts

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Build the Tailwind CSS output:

```bash
npx tailwindcss -i ./src/input.css -o ./src/output.css --watch
```

3. Open `index.html` in a browser, or run a local static server if preferred.

## Notes

This project is a static website, so no backend or database setup is required.
